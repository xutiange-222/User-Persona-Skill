## 你要做的

把这些内容做语义聚类合并:

1. **同义合并**:不同受访者用不同措辞描述同一个本质问题/目标,合并成一条
2. **保留差异**:本质不同的观点要保留,不要硬合并
3. **统计提及**:每条最终输出的观点,标明哪些受访者提过(用 source 字段值)
4. **完整保存**:输出全部与研究问题相关、语义独立且有证据的观点，不按页面容量截断

## 输出格式

只输出 JSON 数组,**不要任何前言后记或 markdown 标题**:

```json
[
  {
    "title": "聚合后的标题(语义完整、简洁、一行可读)",
    "detail": "聚合后的详细描述(具体可观察,带数字/事实)",
    "mention_count": 3,
    "mentioned_by": ["P11111111", "P22222222", "P33333333"],
    "evidence_quotes": [
      "[来源:P11111111]: \"逐字原话片段\"",
      "[来源:P22222222]: \"逐字原话片段\"",
      "[来源:P33333333]: \"逐字原话片段\""
    ]
  }
]
```

## 关键约束

- title:语义完整且可独立读懂,同时尽量一行呈现。中文通常 4-16 字；必须保留动作对象、产品名和技术 token。超长时改写,禁止字符切片、自造缩写、尾部省略号或用“……”代替缺失语义
- detail:具体可观察,≤ 50 字。如果多位受访者提到同一问题但侧重不同,取最具体的那个表述
- mention_count = mentioned_by 数组长度,也必须 = evidence_quotes 数组长度,三者必须一致
- mentioned_by 用受访者的 source 标识(就是输入里 source 字段的值)
- **evidence_quotes 必须全量**:mentioned_by 里的每一位都要给出直接支撑当前观点的逐字原话。找不到直接原话时，不得计入 mentioned_by，也不得借用只在主题上相近的代表性原声
- **观点之间必须语义独立**,不要相似的两条都列出来

按重要性排序(提及次数多 + 描述具体的优先)。
